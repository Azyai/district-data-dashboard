# 门头沟区全域地图数据

`mentougou.geojson` 是驾驶舱随应用分发的 WGS84 矢量底图。

- 区界取自 OpenStreetMap 的行政区关系 `2988898`，于 2026-11-23 获取。[门头沟区关系](https://www.openstreetmap.org/relation/2988898)
- 道路、水系和镇街地名取自 Geofabrik 的 OpenStreetMap 北京数据，快照时点为 2026-11-18 21:21 UTC。复用主要道路和河渠，按区界裁切、简化线条，镇街地名通过名称关联驾驶舱区划编码。同名时优先采用城镇或街道类别的点位。[北京数据集](https://download.geofabrik.de/asia/china/beijing/) · [所用归档](https://download.geofabrik.de/asia/china/beijing/beijing-261118-free.shp.zip)
- 对照资料为京 S(2026)037 号《2026 版北京市行政区域界线基础地理底图（门头沟区）》。[北京市民政局下载页](https://mzj.beijing.gov.cn/art/2026/9/15/art_11098_693210.html)
